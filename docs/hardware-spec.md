# BB-8 真机规格（第一版原型）

电影实物尺寸（starwars.com / rimstar.org 实测）：球径 508mm，头径 295mm（头球比 0.58），总高 670mm。头部不是纯半球：底部有约 31mm 座圈 + 20mm 收口锥台（底径 223mm）。

第一台真机按 **球径 300mm** 等比缩小，好打印、好买零件。指令仍是同一套：`drive` / `turn` / `lookYaw` / `lookPitch` / `emote`。

## 尺寸

| 零件 | 规格 | 备注 |
| --- | --- | --- |
| 球体外径 | 300 mm | 两瓣半球对扣，PETG / ABS |
| 球壁厚 | 2.5–3.0 mm | 太厚会挡磁铁，太薄会瘪 |
| 头部外径 | 175 mm | 0.58 × 球径，电影同比例（508:295）|
| 头壁厚 | 2.0 mm | 头内要放舵机和磁铁 |
| 内部驱动单元占位 | 宽 90 × 长 120 × 高 70 mm | 配重在下，桅杆朝上 |
| 离地间隙 | 0 | 球本身着地，地面摩擦靠外壳 |

电影级下一档：球径 560 mm，头径 260 mm，电机和电池整体加大一号。

## 内部驱动（和仿真同一模型）

- 方案：球内配重底盘 + 一对驱动轮压在内壁 + 顶部磁铁桅杆
- 前进 `drive`：两轮同向转，配重前移，球滚动
- 转向 `turn`：底盘偏航（第三电机或舵机转整机）
- 不要用外部轮子，外壳必须是完整球面

## 磁铁与头部

| 位置 | 规格 | 数量 |
| --- | --- | --- |
| 桅杆顶端（球内） | N52 钕磁 20×5 mm 圆片 | 4–6，同极朝上 |
| 头底（球外） | N52 20×5 mm | 4–6，异极朝下，围成一圈 |
| 磁隙 | 穿过球壁后约 3–5 mm | 壁厚 3 mm 时用 5 mm 厚磁铁 |

头内：

- 偏航舵机：跟 `lookYaw`（±0.7 rad，约 ±40°，不能转到脑后）
- 俯仰舵机：跟 `lookPitch`（±0.35 rad，约 ±20°）
- 万向架让头在球顶滑动时仍能转，不要把头和球壳粘死

## 电控

| 用途 | 型号 | 说明 |
| --- | --- | --- |
| 主控 | ESP32-WROOM-32 DevKit | USB 串口 115200 + BLE Nordic UART |
| 驱动轮 | JGA25-370 12V 200–300 rpm × 2 | 带霍尔更好，方便以后闭环 |
| 驱动轮驱动器 | TB6612FNG 或 DRV8833 | `drive` 映射到 PWM |
| 底盘偏航 | 360° 舵机 或 第三只 25mm 减速电机 | `turn` |
| 头舵机 | MG90S × 2 | `lookYaw` / `lookPitch` |
| 电池 | 3S 18650 1500–2200 mAh，带 BMS | 12V 电机；舵机用 BEC 降到 5V |
| 充电 | USB-C 3S 充电器，或取出充电 | 球上开检修盖 |

固件草稿：`firmware/bb8_bridge.ino`

| 信号 | ESP32 引脚 |
| --- | --- |
| drive PWM | GPIO 25 |
| turn PWM | GPIO 26 |
| lookYaw | GPIO 18 |
| lookPitch | GPIO 19 |

协议一行 JSON，20Hz：

```json
{"drive":0.5,"turn":-0.2,"lookYaw":0.1,"lookPitch":0,"emote":1}
```

`emote`：0 无，1 叫一声，2 兴奋，3 好奇。真机可先用无源蜂鸣器，再换采样音效。

## 建议采购顺序

1. 打印或买 300mm 半球、N52 磁铁，先验证头能吸在球顶、滑动不掉
2. 底盘 + 双轮 + 配重，不装头，先让球能走直线
3. 加偏航，再把头和舵机装上
4. 烧 `bb8_bridge.ino`，用页面上的「连接串口」对同一套指令

仿真单位目前仍是 1.1m 球。等 300mm 样机滚起来，再按实测摩擦和电机特性回调仿真阻尼。
